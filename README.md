# CulturalCompetentML
This repository contains the two datasets (LAMPS and CARPETS) for testing the Cultural Competence of a model and the related code. 


The updated code is in "code" branch, in "main" branch developers added first version of the code.
Samples generated with adversarial sampling and diffusion models are in "generated_images" branch.
"dataset" branch contains just the raw images.
